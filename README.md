# Wumarov releases

This public repo holds the builds of Wumarov Productions games and the list the Wumarov Launcher reads.
There is no source code here.

- `manifest.json`: the games, their latest versions, file hashes and download links, and the launcher's own latest version.
- `art/<game id>/cover.*` and `banner.*`: the pictures the launcher shows.
- The builds themselves are in [Releases](../../releases).

Everything here is written by the publish tool in the private launcher repo. Do not edit `manifest.json` by hand.
